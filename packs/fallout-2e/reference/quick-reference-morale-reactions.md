- Enemies test WIL Morale at first casualty and at half their number down; a lone enemy tests at 0 HP. Groups use the leader's WIL. **PCs never test Morale.**
- Reactions (stranger, unclear mood): 2d6 — **2** Hostile / **3–5** Wary / **6–8** Curious / **9–11** Kind / **12** Helpful.
