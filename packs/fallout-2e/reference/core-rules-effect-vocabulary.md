When a perk, item, background, or relic changes the odds, use concrete effects — not invented intensity knobs. These are the canonical operations the system understands:

- **Attack effects**: Enhanced (d12), Impaired (d4), Blast, ignores N Armor, steps up one damage die (d6 → d8, cap d12). Die steps from different sources add together but never pass d12; Impaired and Enhanced replace the die after all steps.
- **Save effects**: automatically passes / fails; re-rolls a failed save once per scope; save counts as attribute +N / −N; the save is not required; make an immediate save.
- **Reactions / Karma / Faction Rep**: shift one step, or +N / −N to the roll.
- **Resource effects**: +1 Armor (up to the cap of 3); take, heal, or clear a Rad, Fatigue, Deprivation, HP, or STR point; gain or drop inventory slots.
- **Timing scopes**: once per round / combat / scene / session / day / watch; for the rest of the scene; until the next rest.

**Do not write:** "save one step easier," "Morale save one step worse," "Scar heals one step faster," "speed one step higher." Step language only applies to the defined step ladders above. For anything else, state the concrete effect instead.
