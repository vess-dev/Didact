tags: [getting, started]

---
The rules in this book serve the story. If a rule is making the story worse, drop it. Tell the players you're dropping it. Drop it for this scene or for this campaign, not silently and not permanently.

In particular: if a rule is hurting a player who did not deserve it, ignore the rule. If a rule is protecting a player who did deserve it, use the rule. If a rule is making the players feel like they are playing a chess game instead of telling a story, put it aside.

The game is not won. The game is played. Play it.
