Some pre-war drugs, experimental gear, and unusual efforts strain the body in a way that doesn't show up as HP loss. That strain is **Fatigue**.

- **Fatigue fills inventory slots, exactly like Rads.** Each point is one slot.
- A full night's sleep in a safe place clears all Fatigue. Rads and Fatigue do not clear each other.
- A PC with no free slots when asked to take a Fatigue must drop an item to make room.
- Ten slots full (Rads + Fatigue + gear) = 0 HP, same as Rads.

A character is told when something will inflict Fatigue before they commit — chem labels, relic descriptions, and the fiction should warn them.
