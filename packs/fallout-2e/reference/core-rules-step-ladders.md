Several Fallout 2e mechanics use a **step ladder** — a fixed list of named rungs the system can move up or down. The full list of defined ladders is:

- **Reactions** — Hostile → Wary → Curious → Kind → Helpful
- **Terrain Difficulty** — Easy → Tough → Perilous
- **Weather** — Clear/Fair → Cold/Hot/Gusty → Dusty/Harsh → Stormy → Extreme → Catastrophic
- **Supply / bounty die / damage die** — d4 → d6 → d8 → d10 → d12 (d20 is Fat Man only)
- **Faction Reputation** — Vilified → Hostile → Neutral → Liked → Idolized
- **Party Karma** — Hated → Infamous → Shady → Anonymous → Good → Honored → Messiah
- **Weight class** — petty → normal → bulky
- **Companion Loyalty** — Wary → Tested → Trusting → Devoted → True
- **Settlement attribute** — 1 → 2 → 3 → 4 → 5 (Population / Defense / Industry)

An effect that "shifts one step better/worse" moves the value by one rung on the matching ladder.

**Ladders clamp at their endpoints.** A shift that would push past the top or bottom rung has no mechanical effect — the needle does not move. The Overseer should still narrate why. A PC who is already Idolized does not become *more* Idolized; a Reaction roll that is already Helpful does not become a sixth unnamed category; Perilous terrain does not become a fourth difficulty tier.
