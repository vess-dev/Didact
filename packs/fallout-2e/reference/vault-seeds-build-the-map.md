- Drop **6–20 d6** dice on your map, ignoring any that roll off. These are the rooms.
- Mark each die face with the room type.
- If a room feels too isolated, roll another die near it for a new room.
- The room nearest a page edge is the **entrance**.
- Number the rooms, starting from the entrance.

### Die Drop Table

| d6 | Room |
|---|---|
| 1 | Monster |
| 2–3 | Lore |
| 4 | Special |
| 5–6 | Trap |
