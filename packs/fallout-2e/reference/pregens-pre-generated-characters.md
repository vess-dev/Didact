Six ready-to-play characters for a quick start or a one-shot. Attributes are pre-rolled, starting gear is filled in, one table result is picked for each background, and a Bond is selected. One of them (the youngest — the Vault Dweller) carries the Omen.

An Overseer picking pregens should pick four to six and let players claim. If a player wants to customize, let them re-roll any single table result or swap the Bond for a roll on the table.
