1. **Pick the scale.** A small region (a valley, a city) has 6–10 points. A large one has 20+. Bigger isn't better.
2. **Place the points.** Each point should be something a player might want to go to: a settlement, a ruin, a resource, a landmark, a threat.
3. **Connect them.** Not every point connects to every other. Paths should reflect geography. A bridge is a path. A caved-in tunnel is not.
4. **Label the paths.** Each path has a path type (old highway / beaten trail / open wastes) and a cost in watches — its distance (Short +1, Medium +2, Long +3) plus its type (highway +0, trail +1, wastes +2). The shortest hop on an old highway is 1 watch; the shortest trail is 2; the shortest crossing of open wastes is 3.
5. **Hide things.** Some paths are hidden — visible only once discovered, learned from a local, or mapped.
