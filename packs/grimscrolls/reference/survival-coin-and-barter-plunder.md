**Plunder.** Picking over a ruin is set dressing until it matters. When it does, make a story roll for the place — 1d if it's been robbed already, 2d for an ordinary barrow or bandit camp, 3d for somewhere sealed since the First Era. **Perfect:** a minor haul, or a cache that refills one pool (Potions, an alchemist's Satchel, a relic's charge). **Messy:** a find with a catch — it's trapped, it's claimed, it's cursed. **Grim:** nothing, and now something knows you're here. A thorough search takes time; if anything is closing in, roll its pool.

*Didact:* `didact do plunder place=robbed|ordinary|sealed`.
