**Sessions start warm.** Before each session, look back at the last one together: every player shares their hero's best moment and takes **spark** for it, thread and per-session talents reset, and the GM takes **suspense** and stitches the moments into the *"When last we left…"* that opens the night.

After each session, take 1 XP; the GM adds a bonus XP for a standout one (about one session in four). Level up when your XP boxes equal the next level, then clear them; for a slower road, slash each box before filling it. Each level: **a new talent**, and your Core Talent's **Growth** triggers at the listed levels. Cap is **level 7**.

*Didact:* Didact runs pre-session for each hero when a session after the first starts, and gives each 1 XP when a session ends; `didact char advance <hero>` levels up.
