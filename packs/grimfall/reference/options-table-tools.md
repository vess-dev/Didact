- **Token initiative.** If freeform spotlight stalls at your table: at the start of an intense moment, give each player 2 tokens. Spend one before each story beat (usually an action roll); when everyone's spent out, all tokens refresh.
- **Tick pools.** A predictable pool, usually 2d–4d: it never rolls — it drops exactly 1d whenever triggered. Use them alongside ordinary pools for countdowns the table should read like a clock.
- **Writers' room.** Loosen authorship: thread and tangle details no longer need vantage; any player can offer an impact move against their own survivor (taking spark, as a tangle) or add a detail to the world, and only details that help the party cost thread.
- **Active vigilance.** Prefer dice to GM judgment on hidden dangers? The spotlighted PC makes a story roll, shaped by their vantage: perfect = reveal, messy = hint, grim = the strike lands. (A perk that guarantees a hint, like the Pathfinder's *Keen eye*, turns a grim into a hint.)
