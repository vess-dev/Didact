**Tags.** A tag after a perk's name is a string attached to it. No tag, no strings: anyone can take it, once.

**Wells and dice.** Per-session wells and perks (Grit, Sway, Cool, devices, Luck) refill when a new session starts and in downtime; per-scene wells (Might) refill with every scene. **Perk dice don't stack:** however many perks apply to a roll — Core Perks included — they add +1d in total, and the same goes for setups, for chems, and for relics: one die of each kind. Spark, assists, and special dice like the Weak Point die always add on top.
