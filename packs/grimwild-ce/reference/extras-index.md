The book's index (pp. 204-216) is this pack's glossary. `didact define <term>` gives a term's short definition and the rules it links to (`didact define spark`, `didact define vex`). `didact rules lookup <topic>` finds the full rules text, and `didact search <words>` looks everywhere at once.

The index's page numbers from p. 172 on run 2-3 pages off in this edition, and it lists "Homebrew Guidance" and "Flurry", which have no text here.
