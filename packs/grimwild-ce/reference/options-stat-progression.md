Use this rule if you want a way for character stats to be increased.

**When a PC levels up, they can forgo a talent to increase a stat by 1, to a max of 3.** Each character can only do this once. Stat increases can be very impactful—avoid this option for smaller scale games.

*Didact:* `didact char advance` asks talent or stat when this option is on, until the character has raised one.
