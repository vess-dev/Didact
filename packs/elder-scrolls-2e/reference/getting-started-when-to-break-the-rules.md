---
The rules in this book serve the story. If a rule is making the story worse, drop it — out loud, and just for this scene or this campaign, not silently and not forever.

In particular: if a rule is hurting a player who did not deserve it, set it aside. If a rule is protecting a player who did, use it. If the rules are making the table feel like they're solving a puzzle instead of telling a story, put them down and ask the players what their characters do.

The game is not won. It is played. Now go play it.
