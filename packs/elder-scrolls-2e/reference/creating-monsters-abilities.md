---
A distinct action or power a creature can use, in combat or out.

- If it can be meaningfully avoided or defended against by ordinary means, it is an **Attack**, and it interacts with HP.
- If it cannot be meaningfully avoided or defended against by ordinary means, it is an **Ability**.
- If an Ability affects only a single PC, it should generally take effect at once, with no save that round (and perhaps none at all).
- If an Ability can affect a group of PCs, it should generally call for an immediate save.
