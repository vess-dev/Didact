Roll on the Wilderness Description table and note the results. The pair captures both how travelers perceive the country and any unusual natural features it holds. If the terrain was generated using the **Setting Seeds** chapter, weigh how the associated Landmark colors it as well.

> Landmarks help travelers keep their bearings across trackless country, serving as fixed reference points: a lone wind-bent pine, a ruined watchtower, a Dwemer pipe venting steam, a glacier's blue face. Most wilderness landmarks reveal themselves only from a ridge or treetop, though a few stand tall enough to read from anywhere. Some landmarks are _heard_ before they are seen.

Roll 1d20 for each column and combine the results.
