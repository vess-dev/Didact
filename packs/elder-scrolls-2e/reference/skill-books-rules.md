- A Skill Book takes **one inventory slot** while carried, like any book.
- Reading one takes **one turn** in a safe, quiet place — a few minutes of concentrated study. It cannot be done in combat or while Deprived.
- A Skill Book is **consumed when read**, and **only one character can ever benefit from a given physical copy.** Whoever reads it first claims the perk; the book ends up dog-eared, annotated to death, gifted to a college, or simply memorized and discarded. A second character who wants the same perk must find a different copy.
- The perk a book grants is **small and permanent**: a named trick, a save you no longer need to make, a narrow re-roll, +1 maximum HP. No perk ever adds to a save.
- A character may **refuse** to read a book; if they do, it is not consumed and may be carried, gifted, or sold.
- Each entry names the skill the book is known for in Skyrim — One-Handed, Alchemy, Sneak, and so on. That is flavor, like a Spell Tome's school; there are no skills to track.
