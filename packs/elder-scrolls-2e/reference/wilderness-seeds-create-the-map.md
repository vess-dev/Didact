### Create POIs

- Roll **8–12 d6** onto the map, ignoring any dice that fall off the page. These are the Points of Interest (POI) in the wild.
- Write the face-up results on the page using the Wilderness Die Drop Table. For example, a **4** indicates a **Shelter**, which you would mark with the letter "S".
- Pick two opposite points, ideally near the page's edge. These are the wild's entrance and exit.
- Starting at the entrance and ending at the exit, number each POI on the map.
- Roll on the relevant tables for each point and note the results.
- Filter each result through the results you rolled earlier in this process.

#### Wilderness Die Drop Table

| d6 | POI |
| ------- | ------- |
| **1**   | Monster |
| **2-3** | Ruins   |
| **4**   | Shelter |
| **5-6** | Hazard  |
