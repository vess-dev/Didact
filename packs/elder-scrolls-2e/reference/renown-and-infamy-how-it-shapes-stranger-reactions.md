Renown never adds to or subtracts from a die. It decides where a stranger's Reaction starts (Player's Guide → Core Rules → Reactions) when the party meets someone whose attitude is not already obvious:

- **Unknown (0)** — roll the Reaction as usual.
- **Known (+1)** — roll as usual; on Curious or better, the stranger offers some small favor — a drink, a warning, a better price.
- **Renowned (+2)** — skip the roll: strangers start **Kind**.
- **Hero of Skyrim (+3)** — skip the roll: strangers start **Helpful**, and doors open everywhere.
- **Suspect (−1)** — skip the roll: strangers start **Wary**.
- **Infamous (−2)** — skip the roll: strangers start **Hostile**.
- **Reviled (−3)** — strangers flee or reach for a weapon before a word is spoken.

Anything else that shifts a Reaction — a faction's standing, the Lover Stone, a well-judged gift, an obvious threat — shifts it from there. Renown is the party's running head start (or handicap) on every first impression in the province.
