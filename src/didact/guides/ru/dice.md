# Кости

Бросайте все кости через Didact и никогда не выдумывайте результат. Каждый бросок получает ID (`#r12`), попадает в журнал и может быть воспроизведён.

```
didact roll 4d6kh3                          #r12 4d6kh3 → [6 5 3 (2)] = 14
didact roll 'd20 <= @STR' --as freya        #r13 1d20 <= @STR → [7] <= @STR(12) = true
didact roll '6d10>=8f1'                     #r14 6d10>=8f1 → [9✓ 8✓ 3 1✗ 10✓ 4] = 2 successes
didact roll '{d8, d6}kh1' --reason "Freya attacks with two daggers"
```

**Берите выражение в кавычки**, лучше в одинарные: `>`, `<`, `!`, `(`, `{`, `#` и пробелы что-то значат для оболочки. Без кавычек `6d10>=8f1` бросит `6d10` и запишет файл с именем `=8f1`.

## Как читать результат

`#r12 4d6kh3 → [6 5 3 (2)] = 14 (doubles) — reason`

| Метка | Значение |
|---|---|
| `(2)` | отброшена |
| `6!` | взорвалась: из-за неё добавлена следующая кость |
| `1→4` | переброшена или ограничена: было 1, стало 4 |
| `6+6+2` | накопительная кость: её броски сложены |
| `6-1` | пробивающая кость: считается на единицу меньше |
| `9✓` / `1✗` | успех / провал |
| `purr:3` | кость, добавленная эффектом пакета |
| `@STR(12)` | переменная и её значение |
| `([1 2])[8 8 8]` | кости, брошенные на количество, затем пул |
| `(doubles, max)` | флаги для правил: `doubles`, `all-same`, `max`, `min`, `exploded`, `rerolled`, `crit`, `fumble`, `capped` |

Didact выводит каноническую форму того, что прочитал (`4d6k3` → `4d6kh3`), поэтому иное прочтение никогда не пройдёт незамеченным.

## Нотация

| Что | Как писать | Пример |
|---|---|---|
| Кости | `NdX`, `d%` (d100), `dF` (Fate), `d66` (десятки и единицы) | `3d6`, `4dF` |
| Свои кости и кости пакетов | `d{faces}`, `d[name]` | `d{0,0,1,1,2,3}`, `2d[boost]` |
| Оставить, отбросить | `khN` (или `kN`), `klN`, `dlN` (или `dN`), `dhN` | `4d6kh3`, `2d20kl1` |
| Взрыв | `!` на максимальной грани или по условию; `!!` накапливает, `!p` пробивает, `!o` взрывается один раз | `d6!`, `5d10!>=9` |
| Переброс | `r` — пока не перестанет выполняться условие (по умолчанию: наименьшая грань), `ro` — один раз | `2d6r1`, `d20ro<3` |
| Уникальность | `u` перебрасывает повторы, `uo` — один раз | `4d6u` |
| Ограничение | `minN`, `maxN` | `4d6min2` |
| Успехи, провалы | условие сразу после костей; `f` для провалов | `6d10>=8f1`, `12d6>=5` |
| Чётные, нечётные | подсчёт чётных или нечётных костей | `4d6even` |
| Криты | `cs`, `cf` (+ условие) отмечают криты; сумма не меняется | `d20cs>=19` |
| Наборы | `mt` считает наборы совпадений (`mt3`: наборы из 3+) | `10d10mt` |
| Разница | `ms`: сумма − N; с `<=`/`<`: N − сумма | `d20ms15`, `d20ms<=@DEX` |
| Сортировка | `sa` (или `s`), `sd` | `5d6sd` |
| Группы | `{a, b}` + оставить/отбросить/успехи | `{d8, d6}kh1` |
| Арифметика | `+ - * / // %`, скобки | `(1d6+2)*2`, `3d6*10` |
| Сравнения | `== <> < <= > >=`, с пробелами | `2d6 >= 8` |
| Переменные | `@name`, `@record.field`, `@{npc:tom.hp}` | `d20 <= @STR`, `(@level)d6` |
| Брошенное количество | `(expr)dX` | `(2d4)d8` |
| Функции | `min max abs floor ceil round`; `if(c, a, b)`; `default(@x, 0)` | `max(d6, d8)` |
| Шаги костей | `step(die, n)`; `step.extended(…)` идёт по более длинной цепочке d3–d30 | `step(d6, 1)` → d8 |
| Теги, метки | `tag:expr` называет часть; `expr[label]` помечает её | `hope:1d12 + fear:1d12`, `d8[fire]` |
| Повтор | `N#expr` бросает N раз по отдельности | `6#4d6dl1` |
| Макросы пакетов | `pack.name(args)` | `hack.attack(d8, d6)` |

**Пробелы важны:** `2d6>=8` считает кости, на которых выпало 8 или больше (на d6 всегда 0), а `2d6 >= 8` сравнивает сумму. Didact предупредит, если условие успеха невыполнимо.

**Порядок:** модификаторы всегда применяются в таком порядке, как бы они ни были записаны: min/max → взрыв → переброс → уникальность → оставить → отбросить → успехи и провалы → криты → наборы → разница → сортировка.

## Переменные

- `--as <record>` делает доступными числовые поля записи: `@hp`, `@STR`, `@stats.str` и `@<field>` из её блока механики.
- `--var DEX=12` задаёт одну переменную; флаг можно повторять.
- `@sweeney.hp` читает поле другой записи; для ID используйте `@{npc:tom.hp}`.
- Количество костей, вычисленное из переменных, показывается как брошенное: `(@level)d6` при level 2 записывается как `2d6 → [3 4] = 7`, а JSON броска сохраняет выражение и переменные. Брошенное количество показывает свои кости: `(2d4)d8 → ([1 4])[4 4 2 1 7]`.

## Настоящие кости, отмена, воспроизведение, шансы

- `--got 6,3,4` записывает грани настоящих костей в том порядке, в каком их бросили. Взрывы и перебросы берут следующую грань.
- `didact report 'the tower falls' --of 'the tower'` записывает результат, полученный не здесь: вытянутую карту, башню из блоков, монетку. Он получает номер броска и попадает в журнал бросков, а во время сессии становится ещё и событием-результатом. `replay` его пропускает.
- `didact rolls` выводит последние броски.
- `didact undo --event r12 --reason "…"` помечает бросок отменённым. Он остаётся в журнале, а номера бросков никогда не откатываются.
- `didact replay` заново выполняет каждый записанный бросок и проверяет, что он в точности воспроизводится. Каждый бросок берёт значения из своего собственного потока с сидом, так что один бросок никогда не сдвигает другой.
- `didact odds '2d6 >= 8'` даёт точные вероятности (через icepool) или моделирование, когда точный расчёт недоступен.
- `--seed <text>` берёт значения из фиксированного потока: один и тот же сид даёт одни и те же кости.

## Заметки о диалектах

- `r` перебрасывает снова и снова (Roll20). В Foundry `r` перебрасывает один раз — в Didact это `ro`.
- `cs` и `cf` только отмечают криты, как в Roll20. В Foundry они считают успехи; здесь для этого есть условие (`>=19`).
- `d` сразу после костей означает «отбросить наименьшие»: `4d6d1` — это `4d6dl1`.
- `!=` не допускается. Пишите `!6`, чтобы взрывать на 6, или `<>` для «не равно».
