# Ζάρια

Ρίχνετε κάθε ζάρι μέσω του Didact και δεν επινοείτε ποτέ αποτέλεσμα. Κάθε ρίψη παίρνει ένα αναγνωριστικό (`#r12`), μπαίνει στο αρχείο καταγραφής και μπορεί να αναπαραχθεί.

```
didact roll 4d6kh3                          #r12 4d6kh3 → [6 5 3 (2)] = 14
didact roll 'd20 <= @STR' --as freya        #r13 1d20 <= @STR → [7] <= @STR(12) = true
didact roll '6d10>=8f1'                     #r14 6d10>=8f1 → [9✓ 8✓ 3 1✗ 10✓ 4] = 2 successes
didact roll '{d8, d6}kh1' --reason "Freya attacks with two daggers"
```

**Βάζετε την έκφραση σε εισαγωγικά**, κατά προτίμηση μονά: τα `>`, `<`, `!`, `(`, `{`, `#` και τα κενά σημαίνουν κάτι για το κέλυφος. Χωρίς εισαγωγικά, το `6d10>=8f1` ρίχνει `6d10` και γράφει ένα αρχείο με όνομα `=8f1`.

## Πώς διαβάζεται ένα αποτέλεσμα

`#r12 4d6kh3 → [6 5 3 (2)] = 14 (doubles) — reason`

| Σήμανση | Σημασία |
|---|---|
| `(2)` | απορρίφθηκε |
| `6!` | εξερράγη: το επόμενο ζάρι προστέθηκε εξαιτίας του |
| `1→4` | ξαναρίχτηκε ή περιορίστηκε από 1 σε 4 |
| `6+6+2` | ζάρι που συσσωρεύεται: οι ρίψεις του αθροίζονται |
| `6-1` | διεισδυτικό ζάρι: μετράει ένα λιγότερο |
| `9✓` / `1✗` | μια επιτυχία / μια αποτυχία |
| `purr:3` | ζάρι που πρόσθεσε ένα εφέ πακέτου |
| `@STR(12)` | μια μεταβλητή και η τιμή της |
| `([1 2])[8 8 8]` | τα ζάρια που ρίχτηκαν για το πλήθος, και μετά η δεξαμενή |
| `(doubles, max)` | σημαίες για κανόνες: `doubles`, `all-same`, `max`, `min`, `exploded`, `rerolled`, `crit`, `fumble`, `capped` |

Το Didact επαναλαμβάνει την κανονική μορφή που διάβασε (`4d6k3` → `4d6kh3`), ώστε μια διαφορετική ανάγνωση να μην περνά ποτέ απαρατήρητη.

## Σημειογραφία

| Τι | Γράφετε | Παράδειγμα |
|---|---|---|
| Ζάρια | `NdX`, `d%` (d100), `dF` (Fate), `d66` (δεκάδες και μονάδες) | `3d6`, `4dF` |
| Προσαρμοσμένα ζάρια και ζάρια πακέτων | `d{faces}`, `d[name]` | `d{0,0,1,1,2,3}`, `2d[boost]` |
| Κράτηση, απόρριψη | `khN` (ή `kN`), `klN`, `dlN` (ή `dN`), `dhN` | `4d6kh3`, `2d20kl1` |
| Έκρηξη | `!` στη μέγιστη έδρα, ή σε μια συνθήκη· το `!!` συσσωρεύει, το `!p` διεισδύει, το `!o` εκρήγνυται μία φορά | `d6!`, `5d10!>=9` |
| Νέα ρίψη | `r` μέχρι να μην ισχύει η συνθήκη (προεπιλογή: η μικρότερη έδρα), `ro` μία φορά | `2d6r1`, `d20ro<3` |
| Μοναδικά | το `u` ξαναρίχνει τα διπλά, το `uo` μία φορά | `4d6u` |
| Περιορισμός | `minN`, `maxN` | `4d6min2` |
| Επιτυχίες, αποτυχίες | μια συνθήκη αμέσως μετά τα ζάρια· `f` για τις αποτυχίες | `6d10>=8f1`, `12d6>=5` |
| Ζυγά, μονά | μετράει τα ζυγά ή τα μονά ζάρια | `4d6even` |
| Κρίσιμα | τα `cs`, `cf` (+ συνθήκη) σημαδεύουν κρίσιμα· το σύνολο δεν αλλάζει | `d20cs>=19` |
| Σετ | το `mt` μετράει σετ ίδιων (`mt3`: σετ των 3+) | `10d10mt` |
| Περιθώριο | `ms`: σύνολο − N· με `<=`/`<`: N − σύνολο | `d20ms15`, `d20ms<=@DEX` |
| Ταξινόμηση | `sa` (ή `s`), `sd` | `5d6sd` |
| Ομάδες | `{a, b}` + κράτηση/απόρριψη/επιτυχίες | `{d8, d6}kh1` |
| Αριθμητική | `+ - * / // %`, παρενθέσεις | `(1d6+2)*2`, `3d6*10` |
| Συγκρίσεις | `== <> < <= > >=`, με κενά | `2d6 >= 8` |
| Μεταβλητές | `@name`, `@record.field`, `@{npc:tom.hp}` | `d20 <= @STR`, `(@level)d6` |
| Πλήθος από ρίψη | `(expr)dX` | `(2d4)d8` |
| Συναρτήσεις | `min max abs floor ceil round`· `if(c, a, b)`· `default(@x, 0)` | `max(d6, d8)` |
| Βήματα ζαριών | `step(die, n)`· το `step.extended(…)` ακολουθεί τη μεγαλύτερη αλυσίδα d3–d30 | `step(d6, 1)` → ένα d8 |
| Ετικέτες, ονομασίες | το `tag:expr` ονομάζει ένα μέρος· το `expr[label]` του δίνει ετικέτα | `hope:1d12 + fear:1d12`, `d8[fire]` |
| Επανάληψη | το `N#expr` ρίχνει N ξεχωριστές φορές | `6#4d6dl1` |
| Μακροεντολές πακέτων | `pack.name(args)` | `hack.attack(d8, d6)` |

**Τα κενά μετράνε:** το `2d6>=8` μετράει τα ζάρια που φέρνουν 8 ή περισσότερο (πάντα 0 σε d6), ενώ το `2d6 >= 8` συγκρίνει το σύνολο. Το Didact σας προειδοποιεί όταν μια συνθήκη επιτυχίας δεν μπορεί να ικανοποιηθεί.

**Σειρά:** οι τροποποιητές εφαρμόζονται πάντα με αυτή τη σειρά, όπως κι αν γραφτούν: min/max → έκρηξη → νέα ρίψη → μοναδικά → κράτηση → απόρριψη → επιτυχίες και αποτυχίες → κρίσιμα → σετ → περιθώριο → ταξινόμηση.

## Μεταβλητές

- Το `--as <record>` κάνει διαθέσιμα τα αριθμητικά πεδία της εγγραφής: `@hp`, `@STR`, `@stats.str`, και `@<field>` από το μπλοκ μηχανισμών της.
- Το `--var DEX=12` ορίζει μία μεταβλητή και μπορεί να επαναληφθεί.
- Το `@sweeney.hp` διαβάζει πεδίο άλλης εγγραφής· για αναγνωριστικά χρησιμοποιήστε `@{npc:tom.hp}`.
- Ένα πλήθος ζαριών που υπολογίζεται από μεταβλητές εμφανίζεται όπως ρίχτηκε: το `(@level)d6` με level 2 καταγράφεται ως `2d6 → [3 4] = 7`, και το JSON της ρίψης κρατά την έκφραση και τις μεταβλητές. Ένα πλήθος από ρίψη δείχνει τα δικά του ζάρια: `(2d4)d8 → ([1 4])[4 4 2 1 7]`.

## Φυσικά ζάρια, αναίρεση, αναπαραγωγή, πιθανότητες

- Το `--got 6,3,4` καταγράφει τις έδρες πραγματικών ζαριών, με τη σειρά που ρίχτηκαν. Οι εκρήξεις και οι νέες ρίψεις παίρνουν την επόμενη έδρα.
- Το `didact report 'the tower falls' --of 'the tower'` καταγράφει ένα αποτέλεσμα που δεν ρίχτηκε εδώ: μια κάρτα που τραβήχτηκε, έναν πύργο από τουβλάκια, ένα νόμισμα. Παίρνει αριθμό ρίψης και μπαίνει στο αρχείο ρίψεων, και κατά τη διάρκεια μιας συνεδρίας είναι και συμβάν αποτελέσματος. Το `replay` το προσπερνά.
- Το `didact rolls` παραθέτει τις πρόσφατες ρίψεις.
- Το `didact undo --event r12 --reason "…"` σημειώνει μια ρίψη ως αναιρεμένη. Μένει στο αρχείο καταγραφής, και η αρίθμηση των ρίψεων δεν γυρίζει ποτέ πίσω.
- Το `didact replay` ξανατρέχει κάθε καταγεγραμμένη ρίψη και ελέγχει ότι η καθεμία αναπαράγεται ακριβώς. Κάθε ρίψη αντλεί από τη δική της ροή με σπόρο, οπότε καμία ρίψη δεν μετατοπίζει άλλη.
- Το `didact odds '2d6 >= 8'` δίνει ακριβείς πιθανότητες (μέσω icepool), ή προσομοίωση όταν δεν γίνεται ακριβής υπολογισμός.
- Το `--seed <text>` αντλεί από σταθερή ροή: ο ίδιος σπόρος δίνει τα ίδια ζάρια.

## Σημειώσεις για τις διαλέκτους

- Το `r` ξαναρίχνει ξανά και ξανά (Roll20). Το `r` του Foundry ξαναρίχνει μία φορά, και το Didact το γράφει `ro`.
- Τα `cs` και `cf` απλώς σημαδεύουν κρίσιμα, όπως στο Roll20. Στο Foundry μετράνε επιτυχίες· εδώ αυτό είναι συνθήκη (`>=19`).
- Το `d` αμέσως μετά τα ζάρια σημαίνει απόρριψη του μικρότερου: το `4d6d1` είναι `4d6dl1`.
- Το `!=` δεν επιτρέπεται. Γράψτε `!6` για έκρηξη στο 6, ή `<>` για «διάφορο».
