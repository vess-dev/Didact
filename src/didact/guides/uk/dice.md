# Кості

Кидайте всі кості через Didact і ніколи не вигадуйте результат. Кожен кидок отримує ID (`#r12`), потрапляє до журналу й може бути відтворений.

```
didact roll 4d6kh3                          #r12 4d6kh3 → [6 5 3 (2)] = 14
didact roll 'd20 <= @STR' --as freya        #r13 1d20 <= @STR → [7] <= @STR(12) = true
didact roll '6d10>=8f1'                     #r14 6d10>=8f1 → [9✓ 8✓ 3 1✗ 10✓ 4] = 2 successes
didact roll '{d8, d6}kh1' --reason "Freya attacks with two daggers"
```

**Беріть вираз у лапки**, краще в одинарні: `>`, `<`, `!`, `(`, `{`, `#` і пробіли щось означають для оболонки. Без лапок `6d10>=8f1` кине `6d10` і запише файл із назвою `=8f1`.

## Як читати результат

`#r12 4d6kh3 → [6 5 3 (2)] = 14 (doubles) — reason`

| Позначка | Значення |
|---|---|
| `(2)` | відкинута |
| `6!` | вибухнула: через неї додано наступну кість |
| `1→4` | перекинута або обмежена: було 1, стало 4 |
| `6+6+2` | накопичувальна кість: її кидки додано разом |
| `6-1` | пробивна кість: рахується на одиницю менше |
| `9✓` / `1✗` | успіх / провал |
| `purr:3` | кість, додана ефектом пакета |
| `@STR(12)` | змінна та її значення |
| `([1 2])[8 8 8]` | кості, кинуті на кількість, потім пул |
| `(doubles, max)` | прапорці для правил: `doubles`, `all-same`, `max`, `min`, `exploded`, `rerolled`, `crit`, `fumble`, `capped` |

Didact виводить канонічну форму того, що прочитав (`4d6k3` → `4d6kh3`), тож інше прочитання ніколи не залишиться непоміченим.

## Нотація

| Що | Як писати | Приклад |
|---|---|---|
| Кості | `NdX`, `d%` (d100), `dF` (Fate), `d66` (десятки й одиниці) | `3d6`, `4dF` |
| Власні кості та кості пакетів | `d{faces}`, `d[name]` | `d{0,0,1,1,2,3}`, `2d[boost]` |
| Залишити, відкинути | `khN` (або `kN`), `klN`, `dlN` (або `dN`), `dhN` | `4d6kh3`, `2d20kl1` |
| Вибух | `!` на найбільшій грані або за умовою; `!!` накопичує, `!p` пробиває, `!o` вибухає один раз | `d6!`, `5d10!>=9` |
| Перекидання | `r` — доки умова не перестане виконуватися (типово: найменша грань), `ro` — один раз | `2d6r1`, `d20ro<3` |
| Унікальність | `u` перекидає повтори, `uo` — один раз | `4d6u` |
| Обмеження | `minN`, `maxN` | `4d6min2` |
| Успіхи, провали | умова одразу після костей; `f` для провалів | `6d10>=8f1`, `12d6>=5` |
| Парні, непарні | лічить парні або непарні кості | `4d6even` |
| Крити | `cs`, `cf` (+ умова) позначають крити; сума не змінюється | `d20cs>=19` |
| Набори | `mt` лічить набори збігів (`mt3`: набори з 3+) | `10d10mt` |
| Різниця | `ms`: сума − N; з `<=`/`<`: N − сума | `d20ms15`, `d20ms<=@DEX` |
| Сортування | `sa` (або `s`), `sd` | `5d6sd` |
| Групи | `{a, b}` + залишити/відкинути/успіхи | `{d8, d6}kh1` |
| Арифметика | `+ - * / // %`, дужки | `(1d6+2)*2`, `3d6*10` |
| Порівняння | `== <> < <= > >=`, із пробілами | `2d6 >= 8` |
| Змінні | `@name`, `@record.field`, `@{npc:tom.hp}` | `d20 <= @STR`, `(@level)d6` |
| Кинута кількість | `(expr)dX` | `(2d4)d8` |
| Функції | `min max abs floor ceil round`; `if(c, a, b)`; `default(@x, 0)` | `max(d6, d8)` |
| Кроки костей | `step(die, n)`; `step.extended(…)` іде довшим ланцюжком d3–d30 | `step(d6, 1)` → d8 |
| Теги, мітки | `tag:expr` називає частину; `expr[label]` позначає її | `hope:1d12 + fear:1d12`, `d8[fire]` |
| Повтор | `N#expr` кидає N разів окремо | `6#4d6dl1` |
| Макроси пакетів | `pack.name(args)` | `hack.attack(d8, d6)` |

**Пробіли важливі:** `2d6>=8` лічить кості, на яких випало 8 або більше (на d6 завжди 0), а `2d6 >= 8` порівнює суму. Didact попередить, якщо умову успіху неможливо виконати.

**Порядок:** модифікатори завжди застосовуються в такому порядку, хоч би як їх записали: min/max → вибух → перекидання → унікальність → залишити → відкинути → успіхи й провали → крити → набори → різниця → сортування.

## Змінні

- `--as <record>` робить доступними числові поля запису: `@hp`, `@STR`, `@stats.str` і `@<field>` з його блоку механіки.
- `--var DEX=12` задає одну змінну; прапорець можна повторювати.
- `@sweeney.hp` читає поле іншого запису; для ID використовуйте `@{npc:tom.hp}`.
- Кількість костей, обчислена зі змінних, показується як кинута: `(@level)d6` при level 2 записується як `2d6 → [3 4] = 7`, а JSON кидка зберігає вираз і змінні. Кинута кількість показує свої кості: `(2d4)d8 → ([1 4])[4 4 2 1 7]`.

## Справжні кості, скасування, відтворення, шанси

- `--got 6,3,4` записує грані справжніх костей у тому порядку, в якому їх кинули. Вибухи й перекидання беруть наступну грань.
- `didact report 'the tower falls' --of 'the tower'` записує результат, який не кидали тут: витягнуту карту, башту з брусків, монету. Він отримує номер кидка й потрапляє до журналу кидків, а під час сесії це також подія результату. `replay` його пропускає.
- `didact rolls` виводить останні кидки.
- `didact undo --event r12 --reason "…"` позначає кидок скасованим. Він залишається в журналі, а номери кидків ніколи не відкочуються.
- `didact replay` заново виконує кожен записаний кидок і перевіряє, що він точно відтворюється. Кожен кидок бере значення з власного потоку із сидом, тож один кидок ніколи не зсуває інший.
- `didact odds '2d6 >= 8'` дає точні ймовірності (через icepool) або моделювання, коли точний розрахунок недоступний.
- `--seed <text>` бере значення з фіксованого потоку: той самий сид дає ті самі кості.

## Нотатки про діалекти

- `r` перекидає знову й знову (Roll20). У Foundry `r` перекидає один раз — у Didact це `ro`.
- `cs` і `cf` лише позначають крити, як у Roll20. У Foundry вони лічать успіхи; тут для цього є умова (`>=19`).
- `d` одразу після костей означає «відкинути найменші»: `4d6d1` — це `4d6dl1`.
- `!=` не дозволено. Пишіть `!6`, щоб вибухати на 6, або `<>` для «не дорівнює».
